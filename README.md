# Drill AI Intelligence Platform - Frontend

This is the frontend component of the Drill AI Intelligence Platform, a web-based application for oil drilling data analysis. Built with React, Vite, and Tailwind CSS, it provides an interactive UI with well selection, data visualization (charts for rock composition, DT, GR vs. depth), file upload functionality, and a chatbot interface integrated with a backend API.

## Author
- Syed Tayab (syedtayab321)

## Overview
- **Tech Stack**: React 18, Vite, Tailwind CSS, Recharts, React Router, Axios.
- **Features**:
  - Left sidebar for well list selection.
  - Dynamic dashboard with file upload (XLSX) and visualizations.
  - Tabbed navigation (Drilling Monitoring, Offset Wells Map, Bit Summary) with closeable tabs.
  - Chatbot UI for querying uploaded data.
  - Responsive design for desktop, tablet, and mobile.
- **Deployment**: Hosted on GitHub Pages at `https://syedtayab321.github.io/drill-ai-platform/`.

## Prerequisites
